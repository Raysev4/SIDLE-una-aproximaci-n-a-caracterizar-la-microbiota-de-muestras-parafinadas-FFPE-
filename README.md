# SIDLE, una aproximación a caracterizar la microbiota de muestras parafinadas (FFPE) 
Código usado para la realización del análisis de las muestras de mama. 

Se usó docker para crear un contenedor estable con las versiones compatibles de todos los programas y Visual Studio para el código.   

Principalmente se usó la plataforma bioinformática de análisis de microbiota QIIME2, en la cual se integra el algoritmo SIDLE.
